# C# Projects

These are some projects I made using C# and .NET Framework.

## Projects

### CodeFirstConsoleApp
This project is a console application that uses Entity Framework Code-First approach to create and manage a student database. It demonstrates how to create entity models, configure a DbContext, and perform basic database operations like adding and saving student records to SQL Server.

### PolymorphismAssignment
This project demonstrates polymorphism and interface implementation. It includes an Employee class that implements the IQuittable interface, showing how different objects can be treated through a common interface.

### OperatorsAssignment
This project shows how to overload operators in C#. It includes an Employee class with custom equality operator overloading to compare Employee objects.

### MethodsandObjectsAssignment
This project demonstrates creating and using objects in C#. It shows how to instantiate classes and call methods on objects.

### MethodClassAssignment
This project demonstrates working with static methods, method parameters, and output parameters in C#.

### MethodAssignment
This project shows method overloading and working with optional and named parameters.

### ParametersAssignment
This project demonstrates different ways to pass parameters including by reference, by value, and using out parameters.

### MathandComparisonOperatorsAssignment
This project is a console application that takes user input and performs mathematical and comparison operations, demonstrating type conversion and operator usage.

### AbstractClassAssignment
This project demonstrates abstract classes and inheritance in C#. It shows how to create abstract classes and implement abstract methods in derived classes.

### ParsingEnumsAssignment
This project demonstrates working with enums in C#, including parsing strings to enum values and handling invalid input.

### LambdaAssignment
This project demonstrates lambda expressions and LINQ queries for filtering and manipulating collections.

### DateTimeAssignment
This project demonstrates working with DateTime objects, including formatting dates and performing date calculations.

### InputAssignment
This project is a console application that demonstrates reading and processing user input.

### StringsandIntegersAssignment
This project demonstrates exception handling when converting strings to integers, including try-catch blocks and error handling.
